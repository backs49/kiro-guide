# 요금과 크레딧

<span class="level">L1</span> Kiro는 **월 구독 플랜 + 크레딧** 구조입니다. IDE, CLI, Web이 같은 크레딧을 함께 씁니다.

::: danger 가격 수치는 반드시 공식 페이지에서 재확인
아래 수치는 **2026-11-02에 확인한 [공식 요금 페이지](https://kiro.dev/pricing/)와 2026-11-10에 확인한 [공식 FAQ](https://kiro.dev/faq/) 기준**입니다. Kiro 요금제는 2025~2026년에 여러 번 바뀌었습니다(예: 2026년 6월 Pro Max 추가). 예산을 잡거나 사내 보고서에 쓰기 전에 공식 페이지를 다시 확인하세요.
:::

## 플랜 구조 (2026-11-02 확인)

| 플랜 | 월 요금 (USD) | 월 포함 크레딧 | 추가 크레딧 |
|------|--------------|----------------|-------------|
| Free | $0 | 50 | 구매 불가 |
| Pro | $20 | 1,000 | 크레딧당 $0.04 |
| Pro+ | $40 | 2,000 | 크레딧당 $0.04 |
| Pro Max | $100 | 5,000 | 크레딧당 $0.04 |
| Power | $200 | 10,000 | 크레딧당 $0.04 |

- 포함 크레딧은 **매월 초기화**되며 다음 달로 이월되지 않습니다.
- Free 플랜은 일부 모델만 사용할 수 있고 사용량 제한이 있습니다. 사용 가능한 모델은 [Models 문서](https://kiro.dev/docs/models/)에서 확인하세요.
- Kiro Web은 Pro 이상 유료 플랜에서 사용할 수 있습니다.
- 팀 플랜은 공식 FAQ 기준 **좌석당 월 $20, 좌석당 500 크레딧 포함**입니다.
- Enterprise(조직) 플랜과 AWS GovCloud(US) 리전에는 Free 플랜이 없습니다. GovCloud 요금은 상용 리전보다 약 20% 높다고 안내되어 있습니다.

## 크레딧은 어떻게 소모되나

- 크레딧은 **에이전트에 요청을 보내 작업할 때** 소모됩니다. 같은 요청이라도 작업의 크기와 선택한 모델에 따라 소모량이 달라집니다.
- 모델 선택을 **Auto**로 두면 Kiro가 작업마다 적절한 모델로 라우팅합니다. 공식 문서도 대부분의 작업은 Auto로 시작하기를 권장합니다.
- 남은 크레딧은 CLI에서 `/usage`로, IDE에서는 계정·사용량 화면에서 확인합니다. CLI 3.1.0부터는 **현재 세션에서 쓴 크레딧**이 `/usage`와 상태 표시줄, Workflow 단계 행에 표시됩니다.
- [Workflows](/features/workflows)도 같은 크레딧을 쓰며, 단계가 많을수록 더 씁니다.

## 비용을 아끼는 습관

1. **작게 나눠 요청하기**: "이 모듈 전체 리팩터링"보다 "이 서비스 클래스의 중복 쿼리만 정리" 같은 요청이 재작업이 적습니다.
2. **스펙으로 범위를 고정하기**: 범위가 큰 작업은 스펙의 작업 목록 단위로 실행하면 방향이 틀어져 다시 하는 비용이 줄어듭니다.
3. **필요한 컨텍스트만 붙이기**: `#codebase`보다 `#file`, `#folder`로 범위를 좁히면 응답 품질도 좋아집니다.
4. **긴 대화는 정리하기**: CLI에서는 `/compact`로 대화를 요약하거나 `/clear`로 새로 시작합니다.
5. **사용량 확인 습관**: 주 1회 `/usage` 또는 계정 화면으로 소모 추세를 봅니다.
